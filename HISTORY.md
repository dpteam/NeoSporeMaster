# HISTORY.md — история изменений SporeMaster 3

Формат: сверху — свежие изменения. Версии условные, отражают крупные этапы.

## [3.81.0] — PreBakedKeys + устойчивые #include в DDFList (2026-10-11)

### Добавлено / исправлено
- **`PreBakedKeys.txt`** теперь читается `KeyMap` (формат `instance \t group \t name \t path`):
  имена экземпляров берутся авторитетно (проверено, что хешируются), группы — только если совпали.
- **`DdfList` `#include`**: цель ищется сначала рядом с включающим файлом, затем в **родительских
  папках** (до 4 уровней). Раньше не работали списки, лежащие в подпапке `DDFLists`, но
  ссылающиеся на цель от корня `Data` (например `#include DDFLists/Core_DDFList.txt`).
- CLI `keymap` сообщает число строк `PreBakedKeys`.
- Тесты: +4 (итого 154) — синтетические и на реальных `PreBakedKeys.txt` / Wii-`DDFList`.

## [3.80.0] — cell world: чтение/запись байт-точно + дамп (2026-10-11)

### Добавлено
- **`CellWorldFile`** (`0x9B8E862F`, `.world`) — **побайтово точное** чтение/запись (проверено на
  реальных бета-файлах) и текстовый дамп (`populate`/`advect`).
- CLI **`cellworld <in.world> <out.txt>`**.
- Тесты: байт-точный round-trip на реальных файлах (всего 150 тестов).

### Выяснено (ревизия)
- `world` (бета) **совпадает** со SporeModder → реализован и проверен **байт-в-байт**.
  `cell`/`structure`/`globals` — **не совпадают**; `populate` — **заголовок совпал, но маркер
  беты 64 б ≠ 76 б** у SporeModder (разбирать по реальным данным, не реализуем вслепую).

### Добавлено

  (приоритеты), подписи форматов по первым байтам, наборы тестовых архивов.

### Проверено (ревизия)

- **`roundtrip` lossless** на всех релизных и бета-архивах (включая `CompiledMaterials`, `Effects`,

  **не совпадают** с форматами SporeModder.

## [3.70.0] — `list`: маски/regex и поиск по содержимому (2026-10-11)

### Добавлено
- **`NameFilter`** (Core) — фильтр имён: подстрока, **маски** `*`/`?` (`*.rw4`), **regex** (`re:...`),
  с таймаутом и безопасным фолбэком. Применяется к пути, типу и ключу каждого ресурса.
- **`ContentQuery`** + **`ResourceContentSearch`** (Core) — поиск **по содержимому**: `text:<строка>`
  (без учёта регистра) и `hex:<байты>`; можно комбинировать с именем (`ce_*.rw4 text:gRob`).
  Ограничен (по числу прочитанных ресурсов/совпадений), чтобы не тормозить.
- GUI: поиск по содержимому запускается по **Enter**; подсказка в тултипе; **исправлен порядок**
  подписи «Поиск:» и поля (подпись слева). Фильтр имён — по-прежнему мгновенный, без лагов.
- Тесты: маски/regex/подстрока, привязка фильтра к ресурсам, парсинг `text:`/`hex:`, поиск по
  содержимому на реальном архиве (всего 141 тест).

### Проверено
- GUI-самотест: `prop` 184→60, `*.rw4`→74, `re:\.prop$`→56, `hex:00000000`→174 совпадения.

## [3.58.0] — исправления по RW4-превью и истории пакетов (2026-10-11)

### Исправлено
- **История пакетов**: явное открытие (диалог/перетаскивание/командная строка) теперь **сбрасывает**
  историю, поэтому при запуске больше не «кидает» в ранее открытый вложенный пакет. Вложенный (через
  «Открыть как пакет») по-прежнему запоминает родителя (`OpenPackage` vs `OpenNestedPackage`).
- **Текстуры на модели**: каждый меш получает текстуру **своего** материала (слот сэмплера 0), а не
  первую попавшуюся; на `PreviewMesh` добавлен `MeshSectionIndex`.

### Выяснено
- Часть `.rw4`-моделей **не имеет статической геометрии** (ссылка на вершины = «нет объекта», `1<<22`)
  — это **процедурные/анимированные** меши (геометрия генерируется в рантайме). Таким моделям теперь
  выводится пояснение вместо пустого вида. В `BP2_Data`: 26 из 32 моделей с геометрией.
- «Зелёный» цвет у `ce_limb_assembly_01.rw4` — это **реальное содержимое встроенной текстуры**
  (усреднённо R96 G107 B35 — оливковый tint-масочный цвет), а не ошибка декодирования.

## [3.18.0] — исправление вылетов GUI + динамическая отказоустойчивость (2026-10-11)

### Исправлено (критично)
- **Вылеты GUI при любом обновлении списка** (открытие архива, клик по File/Tools/Help).
  Причина: `InvariantGlobalization=true` (наследуется из `Directory.Build.props`) — WPF при
  отрисовке `GridView` падает на `XmlLanguage.GetSpecificCulture()`
  («Cannot find non-neutral culture related to 'en-us'»). Решение: `InvariantGlobalization=false`
  в `SporeMaster.Gui.csproj`.
- Открытие `BP2_Data.package` (и любых архивов) больше не приводит к вылету.

### Добавлено (динамическая отказоустойчивость)
- Глобальные обработчики в `App` (`DispatcherUnhandledException` + `AppDomain.UnhandledException`):
  лог в `%TEMP%\sporemaster-gui-crash.log`, приложение продолжает работу.
- Все обработчики GUI обёрнуты в `Guarded(...)`; декодирование изображений — в `try/catch` с
  hex-фолбэком.
- Самотест (`--selftest`) теперь делает реальный проход раскладки (`Show`/`UpdateLayout`) и
  прогоняет превью **всех** ресурсов — именно это выявляет ошибки конфигурации/отрисовки.
- Документация правил: `AGENT.md` (§1), `docs/ARCHITECTURE.md` (раздел «Обработка ошибок»),
  `README.md`, `MEMORY.md` (§1.9, §1.10).
