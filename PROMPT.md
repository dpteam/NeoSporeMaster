# PROMPT.md — постановка задачи «SporeMaster 3»

> Улучшенная и структурированная версия исходного запроса. Служит ориентиром для дальнейшей
> работы и для ИИ-агентов. Правила работы — в `AGENT.md`, принятые решения — в `MEMORY.md`.

## Исходная идея

Обновить код **SporeMaster** так, чтобы он вобрал в себя изменения и возможности **SporeModder FX**
(материалы в `refs/`), перевести всё на современный **.NET 9 (windows)** и снабдить тестами и
документацией.

## Требования

### Технологии
1. Только **C# / .NET 9**.
2. По возможности **без сторонних библиотек** — всё нативно (BCL).
3. **Динамическая отказоустойчивость**: битые данные не должны ронять программу.

### Форматы
4. Поддержка **всех видов `.package`**, особенно **бета-версии игры** (подсказки в `refs/`;
   эталонный код в `refs/` может быть неточным, но содержит нужные детали).
5. Учесть наработки SporeModder FX, включая сопутствующие `.txt`-файлы (реестры имён и т.п.).

### Проект и процесс
6. Если нет `.git` — создать и использовать.
7. Написать `AGENT.md`, `README.md`, `HISTORY.md`, `MEMORY.md`; улучшить и переписать `PROMPT.md`.

### Языки
8. Интерфейс программы — **English**.
9. **Вся документация — на русском.**
10. Добавить в **список идей** пункт «сделать оба языка» (локализацию приложения).

### Тесты
11. Написать тесты, проверяющие работу **headless и/или через CLI**.

## Материалы в `refs/`

- `SporeModder-FX-master/` — эталонная реализация (Java), реестры `reg_*.txt`, документация.
- `_AlsoOnlyIfNeed/` — код, который может понадобиться (3DTools, TextEditor, SporeMaster, VTreeView).
- `_PackageFilesBetaVer/` — тестовые архивы **бета-версии**.
- `_PackageFilesFinalVer/` — тестовые архивы **релизной версии**.
- `CheckAll/`, `SporeEdit/`, `EAPackageBrowser-main/` — другие реализации формата DBPF.

## Критерии готовности (текущей итерации)

- [x] Решение .NET 9 собирается без ошибок и предупреждений.
- [x] Ядро читает и пишет DBPF (2.0/3.0), включая бета-архивы, и DBBF.
- [x] RefPack-компрессия и декомпрессия байт-совместимы с эталоном.
- [x] CLI покрывает базовые сценарии (просмотр, распаковка, сборка, проверка).
- [x] Тесты зелёные и выполняются headless на реальных архивах.
- [x] Документация написана на русском; список идей содержит локализацию на оба языка.
